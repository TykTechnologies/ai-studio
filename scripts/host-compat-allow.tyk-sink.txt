# Modules AI Studio may require at a higher version than Tyk MDCB (tyk-sink)
# does. Go's version selection then raises them in MDCB's build. The reasons
# are the Dashboard's (scripts/host-compat-allow.tyk-analytics.txt, checked
# 2026-09-30 by lowering each on its own); this list holds the subset MDCB's
# go.mod lags on, checked 2026-10-01. Remove an entry once MDCB catches up or
# the requirer allows its version.

# The OpenTelemetry 1.46 exporter family. MDCB's otel core is already 1.46;
# its exporters lag (otlptracegrpc v1.40.0). weaviate v1.38.12 needs a newer
# otlptracegrpc, and the exporters pull the rest.
go.opentelemetry.io/otel/exporters/otlp/otlptrace                            # otel 1.46 exporters
go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc              # weaviate v1.38.12
go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp              # otel 1.46 exporters
go.opentelemetry.io/proto/otlp                                               # otel 1.46 exporters
go.opentelemetry.io/contrib/instrumentation/google.golang.org/grpc/otelgrpc  # grpc-gateway v2.30 (otel exporters)
go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp                # otel 1.46 family
github.com/grpc-ecosystem/grpc-gateway/v2                                    # otel 1.46 exporters
google.golang.org/genproto/googleapis/api                                    # otel 1.46 exporters
google.golang.org/genproto/googleapis/rpc                                    # otel 1.46 exporters
google.golang.org/protobuf                                                   # otel 1.46 exporters, genproto
